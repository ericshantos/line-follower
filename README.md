# Line Follower

Line-following robot built with a Raspberry Pi Pico.

## Overview

This project implements a line-following robot using a Raspberry Pi Pico, infrared sensors, DC motors, and an H-bridge motor driver.

The robot uses the infrared sensors to detect the line and control the motors accordingly.

## Hardware

* Raspberry Pi Pico
* 2× infrared sensors
* 2× DC motors
* H-bridge motor driver
* Battery pack

## Software

* C++
* Raspberry Pi Pico SDK
* CMake
* Visual Studio Code
* Raspberry Pi Pico VS Code extension
